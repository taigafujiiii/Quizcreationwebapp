## 備考

- **tw-animate-css を削除対象から除外**: JS の `from '...'` 参照は 0 件だが `src/styles/tailwind.css:4` に `@import 'tw-animate-css';` があり Tailwind の @import として実使用中。JS grep だけでは検出できないため誤削除に注意。「残す依存 20」に含める。
- **B グループ 23 依存の削除順序**: これら 23 は現状 `grep -rn "from '<pkg>'" src/` で各 1 件ヒットするが、そのヒット元はすべて本チケットで削除する 29 UI ファイルのいずれか(例: `recharts`←`chart.tsx`、`react-hook-form`←`form.tsx`、`cmdk`←`command.tsx`、`vaul`←`drawer.tsx`、`react-day-picker`←`calendar.tsx`、Radix 各種←同名 UI)。**UI ファイルを削除してから依存を削除**(または同一コミット)すれば参照ゼロが成立する。完了条件の grep は削除後に実行するため自然に 0 件となる。
- **@radix-ui/react-slot / next-themes は残置**: `react-slot` は `button.tsx` / `badge.tsx`(存置)で、`next-themes` は `sonner.tsx`(存置)で使用。DESIGN の「未使用 Radix 15」には含まれない。
- **数値の整合**: DESIGN.md は「ui/配下 46 ファイル中 28 ファイルが参照ゼロ」と記載。実測は `.tsx` 46 ファイル中 28 が未使用(DESIGN と一致)、加えて `.ts` の `use-mobile.ts` も未使用のため削除対象は計 29。`utils.ts`(`.ts`)は使用中で存置。齟齬なし。
- **[要確認・スコープ外]** `Register.tsx` / `ResetPassword.tsx` / `AcceptInvite.tsx` / `RegistrationRequestsManagement.tsx` も App.tsx のルート未登録かつ src 全体で import 0 件(=現状到達不能)。ただし DESIGN S11 の削除対象は Verify のみで、ResetPassword / AcceptInvite は R11(S8)が明示的に修正対象として存置を前提とする。Register / RegistrationRequestsManagement は実ロジックを持ち削除指示がないため**本チケットでは削除しない**。「Verify だけがモック実装で削除・他は将来再配線前提で存置」という区別で扱うが、これらの未配線状態が意図通りかは PM/オーナー確認事項(最終報告に記載)。
